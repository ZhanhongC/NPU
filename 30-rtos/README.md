# RTOS 驱动层

与 Linux 侧**同名条目对齐**，便于对照（对照表见 `../10-common/os-parity.md`）。

## RTOS 侧独有的六件事（每条都该有条目）

1. **地址**：无 MMU/MPU 时 buffer 必须物理连续；固定映射表的布局与冲突
2. **cache**：手工 clean/invalidate 的区间计算、方向错误的表现（读到旧数据 / 丢写）
3. **ISR 约束**：可调用的 API 白名单、栈大小、最长执行时间
4. **内存池**：池大小如何定、耗尽时的既定策略（失败返回 or 阻塞）
5. **电源与时钟**：没有框架兜底，谁负责开、漏开的症状是总线挂死
6. **取证**：ring buffer trace 点布置、串口导出、JTAG 现场保存流程
