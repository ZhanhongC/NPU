# 自研平台

只放**平台私有事实**；通用机制放 `10-common` / `20-linux` / `30-rtos`。

## 该放什么

- 寄存器块与位域速查（必标硅 rev）
- 命令集 / 描述符格式 / 固件握手协议摘要
- 固件版本与驱动版本的对应关系
- 硅版本差异（同一寄存器在不同 rev 上的行为）
- 内部 spec 的存放位置与章节号（不复制原文）
- 与 IP 供应商的结论纪要与工单号

## 建议首个条目

`arch-overview.md`：一张 CPU → 驱动 → 命令队列 → DMA → 计算单元 → 完成中断 的路径图，标出每段的地址空间与时钟域。这张图写出来，后面所有条目都有地方挂。
